# 阶段与出海渠道框架

## 来源与边界

根据用户于 2026-11-02 粘贴的出海增长长文整理为决策与执行规则。原文链接：[tinyray1314 的 X 文章](https://x.com/tinyray1314/status/2089227009029509258)。本次依据是用户提供的正文，未独立验证原文中的企业数据、增长归因和平台现状；不将这些案例数字写成事实或预测。此文是经验来源，不替代业务实验与平台官方规则。

## 先判阶段，再判渠道

| 阶段 | 用什么证据判断 | 优先解决 | 资源配置 |
|---|---|---|---|
| 需求验证/冷启动 | 真实任务、复用与付费意愿尚未稳定 | 找到目标用户、获得反馈、完成价值验证 | 优先目标用户密集且反馈快的路径，集中跑通一个闭环 |
| 寻找可重复获客 | 已有部分复用/付费证据，但来源或成本不稳定 | 验证一到两个可复制来源与承接链路 | 一个主渠道、必要配套；根据资源逐步增加 |
| 放大已验证方式 | 持续留存、业务转化与可承受成本已有证据 | 在边际成本可控下扩量、完善组织与品牌资产 | 分阶段提高预算，观察新增群体质量与成本变化 |

原文的 0–100、100–10,000 等用户区间只作背景示意，不用作 PMF 判定。1000 注册用户、一次病毒传播、发行 Token 或融资均不自动证明需求或可规模化。

阶段判不清时显示“阶段待确认”，用现有证据给条件分支。不要把“有付费用户”直接等同于稳定 PMF。

## 五个候选筛选问题

1. 能看到目标客户在这里寻找或讨论相关问题吗？给观察证据或待查动作。
2. 能在团队可用时间内完成首批动作吗？区分启动时间与见效时间。
3. 流量抵达哪个页面、完成哪个具体产品动作？谁负责承接？
4. 能从来源追踪到有效行为、复用或收入吗？哪些归因仍不确定？
5. 跑通后如何重复、成本如何变化？一次发布不能冒充稳定引擎。

渠道的价值会变化。不能因某个目录或平台曾成功，就声称今天仍免费、有效或有流量红利。不给所有渠道平均分预算。

## 补充渠道与操作卡要求

与 [渠道执行规范](channel-execution.md) 配合使用，只展开与当前产品有关的方向。

| 渠道 | 何时值得比较 | 指南必须落实什么 |
|---|---|---|
| Product Hunt / 产品或 AI 目录 | 受众确实会寻找此类工具，有可演示体验 | 筛选相关平台、核实当前提交规则/费用、准备 Logo/一句话价值/demo/落地页，设置来源追踪；区分一次性发布与持续获客 |
| Reddit / HN / 行业 Discord 等垂直社区 | 有明确聚集的用户、能贡献专业内容 | 指定社区类型、查版规与近期讨论、拟一份解决实际问题的帖子、安排回复和反馈记录；不预设必须养号几个月，不群发广告 |
| Build in Public / 创始人内容 | 创始人能持续分享与目标客户相关的真实进展 | 选择平台、给三条选题与首周排期，使用真实操作、反馈或里程碑；每条连接明确下一步，不虚构收入或用户数 |
| YouTube / 短视频 | 产品结果适合演示，或用户在搜索教程 | 为教程、对比、结果展示分别给脚本/标题假设、素材清单、行动入口与制作成本；长视频搜索意图与短视频推荐流分别衡量 |
| ASO / 插件商店 | 产品实际在相关商店分发，存在安装意图 | 核实商店元数据规则，优化标题、截图与描述，按地区本地化，追踪展示到安装再到激活；自然邀请真实评价，不买评或堆竞品商标 |
| 产品内传播 / 模板 / freemium | 用户完成任务时有自然分享场景，成本可承担 | 明确免费核心价值、付费边界、模板场景、分享入口和邀请链路；追踪接收者有效使用，核算免费额度、推理、奖励与支持成本 |
| 开源 / API / 集成生态 | 目标客户为开发者，或能力可进入现有工作流 | 验证平台受众与分发入口、接入/维护成本、文档、示例和计量；开源需有明确许可决策，stars 不当作客户，接入不保证平台推荐 |
| 销售辅助 / ABM | 高价值客户、采购复杂或已有团队版需求 | 定义理想企业画像和目标账户、触达角度、演示与试点流程、销售/产品分工；用销售成本与毛利判断，不能按固定月费门槛决定雇团队 |
| 渠道合作 / 本地化 | 互补产品或渠道有重合用户与明确共同利益 | 选合作方、列联合交付、渠道成本和责任，先做一轮试点；区分翻译、当地购买习惯、客服、支付与持续维护 |

## 将长文中的强结论变成待验证条件

- 冷启动并非绝对不能投广告。若有明确需求假设、可追踪结果和严格预算，小额付费可用于验证；不要未经验证就扩大投放。
- SEO 不是所有独立站唯一或必然最优的资产。先查需求与意图；SEO、社区、品牌和合作均可能有持续价值，也都需要维护。
- 品牌词广告并非必做。先看竞品占位、自然搜索覆盖和增量价值，再决定是否防守。
- KOL 粉丝量和联盟佣金不能固定套用原文数字。按受众、内容质量、报价、退款、续费与毛利估算；联盟还涉及追踪、优惠泄漏、欺诈和结算成本，不保证锁死 CAC。
- 免费体验需覆盖核心价值并控制成本，不等于无限免费；水印、注册钩子和分享不应妨碍用户完成任务或误导用户。
- 发布榜单、平台推荐、生态集成不等于可预测分发，不承诺排名；不使用换票、刷量、虚假评分或商标误导。
- AI 热点资源站仅在与目标客户和产品相关、有独特价值、素材权利明确且可维护时测试。不能批量搬运内容或用大量低价值页面代替需求验证。
- 软件出海经验不能直接套到 RWA/Token。先区分产品用户、资产持有人与代币参与者，再核实地区、权利、推广与平台资格；不以发行节点作为成熟度证据。

## 网页呈现

首屏用四格摘要展示“当前阶段及证据 / 主要瓶颈 / 本轮重点渠道 / 目标用户动作”。接渠道决策表、操作卡、预算和任务排期。每个推荐渠道展示“渠道动作 → 承接页面/入口 → 产品内有效行为 → 观察与复盘”，不能停留在泛曝光。

没有证据时标假设，不做装饰性成熟度评分。原文作为方法参考放到依据区；不转载全文、推广尾注或未经核实案例数字。
