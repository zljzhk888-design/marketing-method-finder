# 方法与 skill 候选表

仅在选择方向时查阅。名称是候选，交接前确认会话中实际可用。按业务机制判断，不能仅凭“流量少”“想增长”等单个词分流。

| 业务证据或需求 | 优先比较的方法与前提 | 候选 skill |
|---|---|---|
| 客户、问题或付费动机尚不明确 | 客户访谈、行为证据、需求验证；先缩小客户群并验证痛点 | customer-research、product-marketing |
| 不清楚该卖什么或价值主张模糊 | 定位、细分客户、购买理由和替代方案分析 | product-marketing、offers、competitor-profiling |
| 有明确需求，客户会主动搜索 | 搜索内容、技术 SEO、比较页；需检查搜索需求、竞争和见效期限 | seo-audit、content-strategy、competitor-alternatives、ai-seo |
| 有结构化数据与大量不同搜索需求 | 模板页面；先验证页面独立价值和真实需求 | programmatic-seo |
| 客户不会主动搜索，但集中在可识别平台/社群 | 内容分发、社群参与、创作者合作；考虑触达权限和制作能力 | social-content、community-marketing、influencer-marketing、youtube-kol-finder |
| B2B 目标客户可识别、客单价支持人工销售 | 名单研究、个性化外联、演示及销售材料；查看成交周期 | prospecting、cold-email、sales-enablement |
| 有已验证的产品与转化路径，希望加快触达 | 小预算付费获客实验；检查单位经济、追踪和创意供给 | paid-ads、ad-creative、conversion-tracking |
| 已有访问，但合格线索/购买偏少 | 页面诊断、价值表达、信任和摩擦优化；按来源及设备分群 | page-cro、copywriting、form-cro、signup-flow-cro |
| 有线索，成交较少或较慢 | 线索质量、异议处理、培育、销售交接诊断 | email-sequence、sales-enablement、revops |
| 注册后没有到达核心价值 | 首次体验、激活动作、生命周期提醒；先定义有效激活 | onboarding-cro、email-sequence |
| 使用后流失、续费下降或支付失败 | 按流失原因和客户群做留存干预，区分主动/被动流失 | churn-prevention、email-sequence |
| 价格/套餐影响购买、升级或毛利 | 付费意愿研究、套餐与价值指标、升级触点 | pricing-strategy、paywall-upgrade-cro |
| 用户满意且存在自然分享场景 | 推荐或联盟实验；验证分享动机与奖励成本 | referral-program |
| 与其他品牌共享目标受众但不直接竞争 | 联合内容、活动、渠道合作；验证双方利益和分工 | co-marketing、events |
| 新产品或功能发布，有明确目标受众 | 分阶段发布、种子用户、分发与后续转化 | launch-strategy、public-relations |
| 想通过免费资源吸引合格客户 | 资料或工具获客；资源需与付费问题相关，并设计后续承接 | lead-magnets、free-tool-strategy |
| 结果相互矛盾或无法定位漏斗损失 | 事件口径、转化追踪、归因审计；数据缺陷影响决策时优先修复 | analytics-tracking、conversion-tracking、attribution |
| 已有足够流量与稳定指标，要判断两种方案的差异 | 有明确假设、可行样本和观察周期的对照实验；低流量先做定性诊断 | ab-test-setup |
| 多渠道与团队资源需要统筹 | 先定位瓶颈，再安排预算、责任和阶段目标 | marketing-plan |

## 容易误判的情况

- “没客户”可能是没有触达、需求不成立、报价不合适或成交受阻；先看购买路径证据。
- “有访问却没成交”先确认访问是否来自目标客户，别直接重写全站或追加广告。
- 低预算不等于内容渠道免费：核算时间、制作和持续运营成本。
- 转化率很低但样本很少时，优先获取行为反馈，避免武断认定页面有问题。
- 追求短期订单时，不以长期搜索积累作为唯一主方法；销售周期长时，不用一周成交数否定方法。
- 用户指定渠道时，在该约束内改进方法；发现不匹配要解释证据及取舍，不能擅自替换目标。
